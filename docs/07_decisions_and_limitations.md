## 1. 設計判断記録

「なぜそうしたか」を残します。後から変える場合は、理由が今も当てはまるかを確かめてください。

| ID | 判断 | 理由 | 代替案と、採らなかった理由 |
|---|---|---|---|
| D-01 | **静的サイト**（`output: "export"`）で GitHub Pages に公開 | サーバー処理が不要で、運用コストがかからない | サーバー付きのホスティング。このアプリには不要 |
| D-02 | 状態変化のパーティクルを **React Three Fiber の自作 `Points`** で実装 | tsParticles は 2D キャンバスの粒子表現で、3D のシーンの奥行き・回転と合わせられない。粒子ごとに「固体の格子 → 液体の溜まり → 気体の雲」の目標位置へ補間するには、自作が適していた | tsParticles（3D のシーンと別の層になる）。背景の演出にだけ採用 |
| D-03 | 周期表からモーダルへの遷移は **clip-path の円形リビール**（Motion） | 依頼の参考例に沿う。クリック位置から広がるため、どの元素を開いたかが分かる | シェアード要素の遷移（`layoutId`）。今回は clip-path を採用 |
| D-04 | UI の言語は**英語** | 元素名・記号・データが英語のため、取り込みが容易で、表記ゆれが少ない | 日本語・韓国語。多言語対応は対象外 |
| D-05 | 3D の照明は **コード内の `Lightformer`** で構成（HDR をダウンロードしない） | 外部サイトへの通信を避け、社内ネットワークや静的公開でも確実に動かすため | drei のプリセット環境（外部取得が必要） |
| D-06 | 状態変化では、**状態ごとの粒子配置を事前に作り**、粒子ごとに遅延と軌道の揺らぎを与える | 自然な「ほどける」「集まる」動きになる | 一斉に補間（機械的に見える） |
| D-07 | 温度スライダーは**元素ごとの範囲**にする。転移点が 100 K 未満の元素は、300 K までは広げない | 共通の範囲では、He（4 K）などの転移点が左端に潰れる。室温（298 K）を含める要望より、転移点を見やすくすることを優先した | 全元素 0〜6500 K の平方目盛り（初版）。固定の 300 K 以上（He の転移点が潰れる） |
| D-08 | 圧力による沸点の変化は、**トルートンの規則による近似** | 元素ごとの蒸発エンタルピーのデータを持たない | 元素ごとの精密なデータ（データ取得と検証に時間がかかる） |
| D-09 | 粒子・固体・液体の間隔の変化は**誇張**する | 実際の変化量は小さく、画面で見えない | 実測に近い係数（変化が見えない） |
| D-10 | 構造タブは**標準状態（298 K、1 atm）に固定**し、温度・圧力のパネルを置かない | 検討の結果、利用者が判断した。パネルは分子や貴ガスでは効果が薄く、結晶だけに出すと元素ごとに画面が違って分かりにくい。原子の動き（振動）は残した | 全元素にパネル（分子では効果が薄い）。結晶だけにパネル（一貫性がない）。温度で構造が切り替わる仕組み自体は、構造の名前の取得のために残している |
| D-11 | 構造の表示は、**確実に言える元素だけ**を対象にする（Sn、La〜Pm などは除外） | 誤った構造を見せない（Sn の常温は β-Sn、La〜Pm は二重六方） | 近似でどれかの構造を当てる（誤解を招く） |
| D-12 | 中性子数は `round(原子量) − 原子番号` の**推定**で表示し、「≈」と注記する | 同位体ごとのデータを持たない | 最多同位体の表（元素ごとの確認が必要） |
| D-13 | 気体は、発光色を使う元素では**注記**を出す | 多くの気体は無色で、色付きの表示は発光色などの表現であるため | 注記なし（誤解を招く） |
| D-14 | 状態は **React の標準の状態管理のみ**。毎フレーム読む値は `ref` に置く | 規模が小さく、外部の状態管理ライブラリは不要。3D は毎フレームの再描画を避ける必要がある | Redux、Zustand など（過剰） |
| D-15 | WebGL を使う部分は、**動的 import（`ssr: false`）** に集約 | 周期表の初期表示を軽くし、サーバー側の描画（静的書き出し時）で WebGL が呼ばれないようにする | 通常の import（サーバー側で失敗する） |

## 2. 既知の制約

### 2.1 化学・物理の表現
- 状態変化の温度は、1 atm の融点・沸点の実測値（または理論値）が基準。圧力による変化は沸点・昇華点だけを近似し、**融点は 1 atm の値のまま**。
- **臨界点**を扱っていない。高温・高圧で液体と気体の区別がなくなる領域でも、沸点の線を引き続ける。
- C・As は、三重点圧力（C 約 107 atm、As 約 36 atm）を超えると融解するが、常に昇華として扱う。
- He が約 25 atm 以上で固体になることを扱っていない。
- 粒子の間隔の変化は誇張しており、圧縮の誇張は特に大きい。
- 色と質感は、実物に近づけた**表現**であり、測定値ではない。多くの気体は無色。
- 中性子数は推定。電子の軌道はボーア模型の表現で、実際の電子雲ではない。
- 原子番号 104 以上のデータは理論値。At を半金属として扱うこと、Lu・Lr を f ブロックの行に置くことは、一般的な表示に合わせた慣習で、IUPAC の暫定案とは異なる。

### 2.2 構造
- 構造データがある元素は限られる（03 章）。ない元素は Structure タブを無効にする。
- 構造は標準状態のみ。温度・圧力による変化は、物質タブでの粒子・固体・液体の表現に限る。

### 2.3 技術・環境
- WebGL が使えない環境では 3D が表示されない（フォールバック表示は未実装）。
- 確認したのは 1 種類のブラウザ・画面サイズのみ（05 章）。性能は未計測。
- 周期表は幅 880 px 未満で横スクロールする。スマートフォンでの確認は未実施。
- `THREE.Clock` の非推奨警告が出る（ライブラリ内部由来）。
- 依存関係に、`npm install` 時に報告された脆弱性（7 件）が残っている。内容は未調査。
- リポジトリにライセンスの指定がない。
