## リポジトリの構成（抜粋）

```

components/     UI と 3D のコンポーネント（table / detail / three / background）
lib/            データ型、相の判定、物理モデル、質感、結晶構造
data/           元素データ（elements.json）
docs/           本ドキュメント
.github/        GitHub Actions（GitHub Pages へのデプロイ）
```
