## 5. 化学的な正確さの確認

別の作業者によるレビュー（コードと表示内容）の指摘に対応しました。

| 指摘 | 対応 |
|---|---|
| Sn をダイヤモンド構造としていた（常温は β-Sn） | 構造データから除外 |
| La、Pr、Nd、Pm を単純な HCP としていた（実際は二重六方） | 構造データから除外 |
| Se を環状（Se₈）で表示していた（安定な灰色セレンは鎖状） | 鎖状の構造に変更 |
| Og が 0 K でも気体になっていた | 沸点未満は固体（予測）とした |
| 予測値（原子番号 104 以上）が実測値と同じ見た目だった | † と注記を追加 |
| C・As の融点が加圧下の値であることの説明がない | 「Melting (under pressure)」と昇華点の行を追加 |
| 中性子数の推定が、特定の同位体と誤解されうる | 「≈」と推定である旨を明記 |
| 圧力 UI での沸点の近似、三重点（希ガスなど）の扱い | 近似であることの注記と、三重点より低い圧力での直接昇華を実装 |
| H₂ の結合長が実測より長い | 実測値（Å）に変更 |
| Cs の色が銀灰色（実際は淡い金色） | 色の表を追加し、反映 |

未対応: At を半金属として扱う点、Lu・Lr の配置（IUPAC の暫定案と異なる）。

## 7. 開発中に見つけて修正した不具合

| ID | 内容 | 対応 |
|---|---|---|
| B-01 | 操作パネルが 3D の上に重なっていた | パネルを 3D の下に分離 |
| B-02 | 液体の表示で、足元に白い四角い板が出た | メタボールの平面を廃止 |

| B-06 | 低温の元素で、温度スライダーの目盛りラベルが重なった | 近いラベルを 2 段に分け、元素別の温度範囲を導入 |

| B-08 | 構造ビューを広げると、自動フィットの拡大率が打ち消した（現在は構造タブのパネルを廃止） | 構造タブを標準状態に固定 |

## 8. 今後のテスト方針（提案）

- 単体テスト（Vitest）: `lib/phase.ts`（温度帯、`tempRange`、位置⇄温度の変換）、`lib/physics.ts`、`lib/structures.ts`、`lib/materials.ts`。入力と出力が明確な純粋関数が多く、効果が高い。
- ブラウザの自動確認（Playwright）: 周期表 → モーダル → 温度・圧力操作 → 閉じる、の一連の流れ。
- 目視確認（手動）: 状態変化の途中のコマ、3D の見た目、他のブラウザ、スマートフォン。
