# 01. 要件定義書

| 項目 | 内容 |
|---|---|
| システム名 | インタラクティブ 3D 周期表（periodic-table） |
| 版 | 1.0（2026-10-08） |
| 区分 | 学習・デモ用の Web アプリケーション（アニメーション技術の習得を兼ねる） |

## 1. 背景と目的

### 1.1 背景
周期表は 2 次元の表だが、元素の性質（質感、状態、原子の構造）は、見て動かすことで理解しやすくなる。アニメーションと 3D 表現のライブラリ（Motion、React Three Fiber、tsParticles）を実際の題材で使いこなすことも目的とする。

### 1.2 目的
1. 周期表を入り口に、各元素の物質・原子・構造を 3D で確認できること。
2. 温度と圧力を変えたときの状態変化（固体・液体・気体）と、原子・分子の間隔の変化を、アニメーションで自然に見せること。
3. 白と黒を基調にした、専門的な印象のデザインにすること。

### 1.3 想定する利用者
化学に関心のある学習者、および本アプリを教材・デモとして使う開発者。ログインは不要で、個人情報は扱わない。

## 2. スコープ

### 2.1 対象範囲
- 周期表（118 元素）の表示と絞り込み
- 元素ごとの詳細モーダル（物質／原子／構造の 3 つのビュー）
- 温度・圧力による状態変化の表示
- GitHub Pages での公開

### 2.2 対象外
- 化合物、溶液、反応のシミュレーション
- 精密な科学計算（相図の厳密な再現など）。本アプリの 3D 表現と数値は教育用の近似であり、研究や設計には使えない
- 多言語対応（UI は英語のみ）
- ユーザー登録、データの保存、サーバー側の処理
- 同位体ごとの表示、スペクトルなど詳細データ

## 3. 機能要件

優先度: 高（H）、中（M）、低（L）。状態: 実装済み（○）。

| ID | 機能 | 内容 | 優先度 | 状態 |
|---|---|---|---|---|
| FR-01 | 周期表の表示 | 118 元素を族・周期の位置に表示する。ランタノイドとアクチノイドは別行に表示する | H | ○ |
| FR-02 | カテゴリ絞り込み | 10 カテゴリ（アルカリ金属、遷移金属など）で絞り込み、該当しない元素を薄く表示する | M | ○ |
| FR-03 | ホバー表示 | 元素にカーソルを合わせると、中央のパネルに記号・名称・原子量・カテゴリを表示する | M | ○ |
| FR-04 | 詳細モーダル | 元素をクリックすると、クリックした位置から円形に広がる遷移（clip-path）で詳細モーダルを開く | H | ○ |
| FR-05 | モーダルを閉じる | Esc キーまたは Close ボタンで閉じる。開くときの逆の動きで閉じる | H | ○ |
| FR-06 | 物質ビュー | 固体・液体・気体の 3 状態を 3D で表示する。元素ごとの色と質感を反映する | H | ○ |
| FR-07 | 状態変化の演出 | 状態が変わるときは、パーティクルが固体の格子・液体の溜まり・気体の雲へ移り変わる | H | ○ |
| FR-08 | 温度スライダー | 元素ごとの温度範囲、転移点マーク（クリックでジャンプ）、キー操作（←/→ で 1 K、Shift で 10 K）、相ごとに同じ幅にするモード | H | ○ |
| FR-09 | 圧力スライダー | 0.001〜1000 atm（対数目盛）。1 atm に吸着する | M | ○ |
| FR-10 | 間隔の変化 | 温度と圧力に応じて、固体・液体・気体の粒子の間隔を変える（誇張あり） | M | ○ |
| FR-11 | 利用できない状態 | データがない、または安定でない状態のボタンを無効にし、理由を注記する | H | ○ |
| FR-12 | 原子ビュー | 陽子・中性子の核と、電子殻ごとの軌道を周回する電子を表示する | H | ○ |
| FR-13 | 構造ビュー | 分子または結晶の構造を、標準状態（298 K、1 atm）で表示する。原子は熱振動し、結合の棒は追従する | H | ○ |
| FR-14 | 3D 操作 | ドラッグで回転、ホイール・ピンチで拡大縮小、右ドラッグで移動。操作するまでは自動回転する | H | ○ |
| FR-15 | 元素情報 | 原子量、カテゴリ、族・周期、密度、融点・沸点、電気陰性度、電子殻、電子配置、外観、要約を表示する | H | ○ |
| FR-16 | 注記 | 予測値（原子番号 104 以上）、昇華する元素、気体の発光色、近似の旨を画面に明記する | H | ○ |
| FR-17 | 背景演出 | メイン画面に、控えめなパーティクルの背景を表示する（tsParticles） | L | ○ |
| FR-18 | 公開 | GitHub Pages で公開できる（静的書き出しと自動デプロイ） | M | 設定済み・**有効化は未了**（06 章参照） |

## 4. 非機能要件

| ID | 区分 | 要件 | 状態 |
|---|---|---|---|
| NFR-01 | デザイン | 黒背景と白を基調とし、アクセントの色は最小限にする | ○ |
| NFR-02 | 言語 | UI は英語。文書は日本語 | ○ |
| NFR-03 | 性能 | 一般的なデスクトップの GPU で、3D 操作が滑らかに動くこと。目標値（fps）は定めていない | **未計測** |
| NFR-04 | 対応環境 | WebGL が使える最新のデスクトップブラウザ | Chromium（ソフトウェア描画）でのみ確認。他のブラウザは**未確認** |
| NFR-05 | レスポンシブ | 周期表は幅 880 px 未満で横スクロール。モーダルは狭い画面で縦に積む | 実装済み。**スマートフォンでの確認は未実施** |
| NFR-06 | アクセシビリティ | キーボード操作（Tab、Esc、矢印キー）、ARIA 属性、フォーカス表示 | 一部実装。スクリーンリーダーでの確認は**未実施** |
| NFR-07 | セキュリティ | サーバー処理と秘密情報を持たない。個人情報を扱わない | ○ |
| NFR-08 | 保守性 | TypeScript、ESLint を通る状態を保つ | ○（`npm run lint` と型チェックが通る） |
| NFR-09 | 正確性 | 化学的に誤解を招く表示をしない。近似と予測値は明記する | 実施（04 章、07 章参照） |
| NFR-10 | ライセンス | 元素データの出典とライセンス（CC BY-SA 3.0）を画面に表示する | ○（フッター） |

## 5. 制約・前提

- 技術: Next.js 15（App Router）、React 19、TypeScript、Tailwind CSS 4、Motion、React Three Fiber / drei、three.js、tsParticles
- 公開先は GitHub Pages のため、**サーバー側の処理は使えない**（静的書き出しのみ）
- 3D の HDR 環境マップはネットワーク取得に頼らず、コード内の照明で構成する
- 元素データは Periodic-Table-JSON（Bowserinator）をもとに整形したものを同梱する

## 6. 受入基準

| No. | 基準 |
|---|---|
| AC-01 | 周期表に 118 元素が表示され、カテゴリで絞り込める |
| AC-02 | 任意の元素をクリックすると、クリック位置から円形に広がってモーダルが開き、Esc で閉じる |
| AC-03 | 物質ビューで、温度・圧力の操作に応じて相が切り替わり、切り替え時にパーティクルの演出が入る |
| AC-04 | 状態が存在しない元素（例: Og の液体、C の液体）で、その状態のボタンが無効になる |
| AC-05 | 原子ビュー、構造ビューをドラッグ・ホイールで回転・拡大縮小できる |
| AC-06 | ブラウザのコンソールにエラーが出ない |
| AC-07 | `npm run lint`、型チェック、`npm run build` が成功する |

受入基準の確認結果は [05 テスト仕様・結果報告書](05_test_report.md) を参照。
